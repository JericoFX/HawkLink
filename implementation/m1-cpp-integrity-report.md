# M1 Integrity — C++

Implementación C++20 congelada para GREEN externo: `include/hawken/package_integrity.hpp`, `src/package_integrity.cpp` y `tests/package_integrity_tests.cpp`. Conserva la API del brief y utiliza únicamente SHA del padre, biblioteca estándar, JSON y doctest ya vendorizados.

El verificador captura los bytes completos del manifiesto, compara su SHA-256 con la confianza explícita del caller y sólo después valida el esquema y recorre paquetes. Comprueba tamaño y SHA actuales, faltantes y extras recursivos; ignora archivos ajenos al listado cerrado de extensiones `.upk`, `.u`, `.udk`. No usa los campos históricos para aprobar archivos. `verified_count` cuenta coincidencias de tamaño y SHA aunque otras incidencias hagan fallar el informe. Cualquier incidencia impide PASS; no repara ni escribe entradas.

Rechaza links en raíces, manifiesto, ancestros y árbol; Windows comprueba además `FILE_ATTRIBUTE_REPARSE_POINT` para incluir junctions. No usa enumeración que omita permisos denegados. Los fallos de lectura/inspección producen `READ_ERROR`; los detalles no copian contenidos ni excepciones que puedan exponerlos.

Tests con archivos temporales: intactos y las tres extensiones, hash/tamaño incorrectos, ausencia/extras, archivos ajenos permitidos, confianza/metadatos/estructura inválidos, baseline vacía, rutas absolutas/traversal/collisiones/aliases Windows y enlaces. La revisión añadió casos de manifest/raíz/ancestro enlazado, manifiesto no regular, digest inválido, root ausente, nombres Unicode y paquete bloqueado para lectura en Windows. Los tests comprueban preservación de bytes, sin debilitar casos previos. Doctest registra skips explícitos de enlaces cuando faltan permisos y comunica el motivo.
